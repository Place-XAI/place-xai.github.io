Continual integration of single-cell multimodal data with MIRACLE

Jiahao Zhou · Jing Wang · Shuofeng Hu · Tongtong Kan · Chao Feng · Xiaohan Qiang · Guohua Dong · Jinhui Shi · Runyan Liu · Xiaochen Bo · Le Ou-Yang · Xiaomin Ying · Zhen He Published 2026-07-31 DOI 10.1038/s43588-026-01030-9 Source nature.com ↗
Core Conclusion

Single-cell atlases today are rebuilt from scratch every time new data arrive — a cost that grows without bound. MIRACLE replaces full reintegration with continual (online) learning: a multimodal VAE (MIDAS) extended with dynamic architecture adaptation for newly arriving modalities/features and a bounded rehearsal memory maintained by distribution-preserving reservoir sampling (DPRS) with ball-tree sampling (BTS). The result is accuracy comparable to offline reintegration (scIB/scMIB) while per-update time and memory stay flat as batches accumulate — on the 2.3M-cell HLCA it ran over an order of magnitude faster than its offline counterpart. Applied to respiratory infections, continual integration refined a healthy PBMC atlas from 13 to 23 cell types and exposed both shared and pathogen-specific immune signatures across COVID-19, influenza A and tuberculosis.

Why It Matters

  • Breaks the O(all-data) update curve. Every atlas project silently pays a quadratic-ish tax: each new dataset triggers reintegration of everything before it. MIRACLE makes the update cost independent of history length — per-integration time flat, memory footprint constant — which is what actually decides whether a living atlas is maintainable.
  • Solves catastrophic forgetting for omics, not just for benchmarks. Existing online methods split into generalization-based (project new data onto a frozen reference; blind to unseen variation) and fine-tuning-based (adapt, then forget). MIRACLE's rehearsal memory is the missing middle, and the paper shows the failure modes concretely — totalVI and trVAE integrate well offline but their scArches-based online versions fail to mix batches.
  • Handles mosaic data, which is what real accumulation looks like. New datasets do not arrive with the same assays: they add ATAC, drop ADT, change feature spaces. Dynamic architecture adaptation lets one model absorb ATAC+RNA+ADT combinations arriving in any order — a capability the surveyed online methods lack entirely.
  • Turns a model into a shareable, updatable artifact. The host builds a reference model; users update it with their own data and reshare, or use it for label transfer. That is a collaboration protocol, not just an algorithm — knowledge accumulates in weights rather than in ever-larger data downloads.
  • Discovery, not only bookkeeping. Label transfer with kNN + novelty detection flagged exactly the genuinely new query cell types (Cycling B and germinal-centre B in tonsil, progenitors in bone marrow), and the cross-disease application produced testable immunology (HERC1+ T cells and PD-1/PD-L1 enrichment in flu A; elevated MAIT fractions in COVID-19, flu A and TB versus healthy).

Core Methods

  • Base model — multimodal VAE (MIDAS): a deep generative model that disentangles biological state from batch/technical factors and natively supports mosaic inputs (ATAC + RNA + ADT in arbitrary presence patterns). MIRACLE wraps it in a continual-learning loop: at each time t, model θt−1 is updated to θt on new data plus rehearsal memory, and inference re-emits embeddings for all data seen so far.
  • Dynamic architecture adaptation: when a new batch introduces an unseen modality or new features, the network is expanded rather than retrained — the mechanism that makes online mosaic integration possible at all.
  • Data rehearsal against catastrophic forgetting: a bounded buffer of past cells is replayed with each update. Ablations make the effect legible: MIRACLE-offline (all data at once) is the no-forgetting upper benchmark, MIRACLE-transfer (no rehearsal) the forgetting-prone lower benchmark, and MIRACLE-generalization the frozen-reference projection baseline.
  • DPRS + ball-tree sampling (BTS): distribution-preserving reservoir sampling caps memory at a fixed cell budget; BTS partitions the embedding space with a ball tree and draws from each partition, so rare populations survive downsampling. Benchmarked by maximum mean discrepancy (MMD) with a Gaussian kernel against simple random sampling, Sketch (Seurat v5) and scSampler over sampling ratios down to 1/32, with 10,000 reference cells and 50 repeats — BTS attains the lowest MMD mean and variance at SRS-level speed.
  • Evaluation: scIB for unimodal/bimodal integration (batch correction vs. biological conservation), scMIB for mosaic/multimodal, plus continual-learning stability metrics over time, neighborhood overlap with the offline gold standard, and label-transfer micro/binary F1. Compared against 11 state-of-the-art methods across horizontal, rectangular and mosaic families (Geneformer, PCA, SCALEX, trVAE, totalVI, Multigrate, scVAEIT and others), with scArches-style fine-tuning added to methods lacking native online support.
  • Label transfer with novelty detection: a kNN classifier over the shared embedding assigns query labels and flags cells that match no reference neighborhood as Unknown — the mechanism that recovered genuinely new cross-tissue cell types.
  • Downstream biology: third-party annotation with Seurat FindTransferAnchors/TransferData, Azimuth (RNA and ATAC applications), SingleR, plus marker dot plots, cytotoxicity/exhaustion scores, GSEA, two-sided Wilcoxon rank-sum tests and differential expression with FDR control.

① Stress-test the framework over long horizons: does MIRACLE lose plasticity?

Extending this paperMIRACLE is validated over horizons of tens of batches (42 for DHCM, 48 studies for HLCA, 34+10+7+20 in the respiratory application). But rehearsal-based continual learners are known to fail in a second, subtler way beyond forgetting: the network gradually loses the ability to learn new things at all, as effective rank and gradient diversity collapse. The paper's own metrics (scIB over time, neighborhood overlap) would not detect this — they measure retention, not remaining plasticity. A direct extension: run MIRACLE for hundreds of synthetic arrivals, track effective rank / dormant-unit fraction of the MIDAS encoder alongside scIB, and test whether continual backpropagation or shrink-and-perturb resets restore capacity. This also sharpens the paper's task taxonomy — arrivals here mix domain-incremental (new batch, same cell types) and class-incremental (new cell types, new tissues) shifts, and rehearsal budgets should arguably differ between the two.

Added value to my researchMy spatiotemporal models face exactly this arrival structure: monthly mobile-phone and POI extracts are domain-incremental drift, while a new city or a new pandemic wave is class-incremental. A plasticity-audited continual GeoAI model would let an accessibility or urban-health predictor absorb each new month without the annual full retrain that currently gates my pipelines — and would tell me when a model has quietly stopped adapting rather than discovering that after a forecast fails.

② Lift ball-tree sampling out of cell space into a general geometry-aware coreset

Extending this paperBTS is the paper's quiet workhorse: partition the learned embedding with a ball tree, sample within partitions, and the retained 20K cells (1/26 of DHCM) preserve the distribution better than random sampling, Sketch or scSampler at SRS-level speed. Yet it is presented purely empirically — no bound relating tree depth and partition radius to the resulting MMD, and no use of the label or rarity structure the atlas already knows. Extending the paper: derive an MMD bound as a function of ball radius and per-partition draw, then make the buffer importance-weighted — over-retain rare populations and cells near modality boundaries, which is where mosaic integration is most fragile. A second extension: since the ball tree lives in an embedding that keeps changing, quantify how stale buffer geometry becomes across updates and when the tree must be rebuilt.

Added value to my researchBTS is, structurally, a spatially stratified coreset — and geography has a native ball tree (great-circle distance). This gives me a principled replacement for the ad-hoc sampling I use when training spatial models on billions of GPS pings or grid cells: build the tree in a learned place-embedding space rather than raw coordinates, so the retained sample preserves the joint distribution of built environment, demography and mobility rather than just spatial spread. It also connects directly to spatiotemporal KDE — BTS partitions are essentially adaptive-bandwidth cells, and the MMD criterion offers an objective way to pick them.

Cross-ref (corpus): A cell atlas foundation model for scalable search of similar human cells — 10.1038/s41586-024-08411-y

③ Close the privacy gap in the "update-and-reshare" protocol

Extending this paperFigure 1c proposes something socially ambitious: a host publishes a model, users update it on their own data and reshare, knowledge compounds in weights. But the paper's own mechanism undercuts the privacy story — the shared model carries a rehearsal buffer of real cells, so resharing means redistributing patient-derived data, and nothing in the framework provides provenance, versioning or protection against a malicious update. Extending the paper: replace the raw buffer with generative rehearsal (the MIDAS decoder can synthesize replay samples), add differential-privacy accounting to the update step, and formalize the multi-host case as federated continual learning with a merge policy — plus a signed lineage record of which datasets shaped which weights. That would turn an appealing diagram into a deployable governance protocol for consortium atlases.

Added value to my researchThis is the blocker in nearly every health-geography collaboration I run: individual-level health records, mobile-phone traces and telehealth utilization cannot cross jurisdictional lines, so multi-region accessibility studies degrade into aggregated proxies. A generative-rehearsal continual model would let each health authority contribute model updates instead of data, and the lineage record answers the reviewer question I always get — which jurisdiction's data drove which coefficient. It also fits my FAIR/open-science line: sharing an auditable model is a publishable, citable artifact when the underlying data can never be.

④ Mosaic integration as the general grammar of multi-source data fusion

Extending this paperThe most transferable idea in the paper is not "single-cell" at all: it is that arriving datasets have ragged modality coverage — DOTEA's eight batches span four different omics combinations — and that a dynamically expanding VAE can absorb them without a common feature space. The paper demonstrates this but never characterizes its limits: how much modality overlap is needed before a newly arriving assay can be anchored, and what happens when a modality appears only in late batches with no overlap to the reference? A crisp extension is a modality-overlap phase diagram — sweep the shared-feature fraction and the arrival order, and map the region where mosaic integration succeeds versus collapses into modality-specific clusters. Pairing that with an explicitly partially-shared embedding (private plus shared latent subspaces) would also make explicit which biology is modality-specific rather than folding everything into one latent.

Added value to my researchMy data landscape is mosaic: smart-card records for some cities, survey travel diaries for others, social-media geotags where platforms permit, remote sensing everywhere, mobile-phone records only under contract. I currently handle this by intersecting down to the lowest common denominator — which throws away most of the signal. Recasting urban data fusion as mosaic integration with a dynamically expanding encoder means a city with only remote sensing plus POIs can still be embedded in the same latent space as a city with full mobility data, and the phase diagram tells me the minimum overlap needed before adding a new sensor type is worth the effort.

⑤ Give the "Unknown" flag a calibrated, explainable footing

Extending this paperMIRACLE's most scientifically consequential output is a negative one: the kNN novelty detector that labels a query cell "Unknown" and thereby claims a new cell type. In the paper this works impressively — the flagged cells were exactly the tonsil germinal-centre B and bone-marrow progenitor populations — but it rests on a distance threshold reported through F1, with no calibrated error control. Since MIRACLE keeps updating, the reference itself drifts, so a fixed threshold cannot hold a constant false-discovery rate over time. Extending the paper: wrap the detector in conformal prediction with a rehearsal-buffer calibration set, so "Unknown" comes with a guaranteed error level that survives model updates, and audit whether the flag reflects genuine biology or residual technical artifact — attributing each novelty call to the features and modalities driving it. The result would be a discovery pipeline that reports this many new cell types at 5% FDR rather than a per-figure F1.

Added value to my researchThis maps one-to-one onto transferring a trained accessibility or health-risk model to an unseen city: the honest question is not "what is the prediction" but "is this place outside the reference manifold, and by how much". A conformal, drift-aware novelty layer would let me report calibrated coverage for 2SFCA-style predictions in cities with no local calibration data — and pairing it with explainable ML (which features made this neighborhood out-of-distribution) turns an OOD warning into a data-collection recommendation. That combination of calibrated uncertainty plus feature attribution is exactly the standard I want for explainable spatial prediction.
