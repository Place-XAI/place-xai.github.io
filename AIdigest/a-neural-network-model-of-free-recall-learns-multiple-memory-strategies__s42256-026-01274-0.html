A neural network model of free recall learns multiple memory strategies

Moufan Li · Kristopher T. Jensen · Qiong Zhang · Qihong Lu · Marcelo G. Mattar Published 2026-07-20 DOI 10.1038/s42256-026-01274-0 Source nature.com ↗
Core Conclusion

Neural networks trained to maximize free-recall performance do not converge on one memory mechanism: they spontaneously discover several distinct retrieval strategies, only some of which resemble classic temporal context models (TCM). The best performers abandon temporal context entirely and instead learn a stimulus-invariant "index code" that tags each item by its studied position, building a stable scaffold for forward sequential retrieval — the computational signature of the memory palace (method of loci) used by human memory experts. This index code emerges preferentially when networks are pushed to recall all items rather than just the next few (high discount factor) and are denied recency (working memory flushed). Human-like recall curves are therefore degenerate evidence — the same behaviour can arise from multiple different computations.

Why It Matters

  • Breaks the one-mechanism monopoly in memory theory. For two decades, recency + forward-asymmetric contiguity were read as fingerprints of a single mechanism (temporal context drift). This paper shows those same behavioural signatures are produced by at least three separable computational solutions — a direct challenge to model identifiability in cognitive science.
  • Gives the "memory palace" a mechanistic account for the first time. The method of loci has been empirically superior for millennia and validated by neuroimaging, but classic models never generated it. Here it falls out of optimization as a positional index code — mnemonic expertise becomes a normative, learnable strategy rather than a trick.
  • Identifies the training conditions that select a strategy. Two controllable knobs — the reward discount factor (recall everything vs. the next few items) and the fraction of working memory flushed (recency availability) — determine which mechanism a network converges to. That converts "individual differences in memory" from a descriptive label into a manipulable objective-function question.
  • Behaviour alone cannot arbitrate mechanisms. The paper is a general warning to any field fitting process models to summary curves: matching a conditional-recall-probability curve does not identify the underlying computation. Representational analysis (index vs. identity decoding) was required to tell the strategies apart.
  • Strategy predicts performance. Index-code usage, forward asymmetry and temporal organization all correlate positively with recall accuracy in models, and the same behavioural correlations hold in 186 human participants — so the model's strategy axis is not an artifact of the simulator.

Core Methods

  • Task-optimized recurrent agent. A GRU-based recurrent network coupled to an episodic memory store is trained end-to-end on a two-phase free-recall task (study phase → response phase), rather than being hand-specified to reproduce recall curves.
  • Reinforcement learning objective. Recall is framed as sequential decision-making and optimized with policy-gradient/actor–critic RL (the A3C family, Mnih et al. 2016). The discount factor is the key normative knob: γ→1 rewards recalling the whole list, low γ rewards grabbing the next few items.
  • Recency ablation via working-memory flushing. A controlled fraction of the recurrent state is wiped at the study/response boundary (% WM flushed, e.g. 0.9), removing the network's ability to exploit recency and forcing it to build a retrieval scaffold.
  • Behavioural fingerprinting. Models and humans are scored on the same classic metrics — conditional recall probability (lag-CRP), forward asymmetry, and temporal organization score — enabling like-for-like model/human comparison and strategy classification.
  • Representational decoding (the discriminative test). Linear decoders trained with cross-validation on 5,000 trials recover item identity vs. item index (studied position) from hidden states at each time step; cross-decoding (train at one position, test at another) diagnoses whether the index code is stimulus-invariant — the property that defines the memory-palace solution.
  • Geometry analysis. PCA trajectories of hidden states in study and response phases, plus state-similarity and key/value cosine-similarity matrices, expose the scaffold geometry rather than treating the network as a black box.
  • Architecture ablation. A key–value memory variant is trained to test whether the strategy is architecture-specific; keys carry more index information and values more identity information — a clean functional dissociation, and the same memory-palace behaviour emerges.
  • Causal manipulations of the input. Injecting a slowly drifting external temporal context pushes models back toward TCM-like strategies (Fig. 5), and enabling content-based (similarity) memory search discourages the memory palace (Fig. 6) — the paper does not merely observe the strategies, it shows what causes each.
  • Population statistics over seeds. Every claim is made over ensembles (n = 20 or n = 83–100 models) with error bars and per-model dots, treating "which strategy a network learns" as a distribution rather than a single run.

① Give the index code a metric: from ordinal position to a geometric scaffold

Extending this paperThe paper's winning solution is a stimulus-invariant index code over ordinal studied position — a 1-D ladder. But the human memory palace it is named after is explicitly 2-D/3-D and spatial: loci sit in a room, with distances, adjacencies and landmarks. A direct extension: replace the ordinal index with a learned metric scaffold (a low-dimensional embedding with a distance function), and test whether recall accuracy, noise robustness (Fig. 4) and capacity improve when the scaffold has geometry rather than mere order. Concretely, re-run the Fig. 3 representational analysis asking whether the network's index subspace is ring-like, line-like or manifold-like, and whether models with richer scaffold geometry survive longer lists. This would test whether the paper's claim "index coding is optimal" is really "a metric scaffold is optimal, and ordinal index is its degenerate 1-D case".

Added value to my researchThis is exactly the abstraction I need for spatiotemporal sequence representation in mobility work. My GPS-trajectory and mobile-phone analyses currently encode a person's day as an ordered sequence of stays; the index-vs-metric distinction says I should compare (a) a positional encoding of visit order against (b) a learned metric scaffold over activity space, and see which better supports next-location and re-visit prediction. It also reframes spatial entropy: an agent with a stable metric scaffold should show low entropy in scaffold coordinates even when raw location entropy is high — a cleaner measure of behavioural regularity than the raw-visit entropy I currently compute.

② The degeneracy warning, imported into spatial model identifiability

Extending this paperThe paper's deepest methodological result is behavioural degeneracy: recency plus forward-asymmetric contiguity — long treated as the fingerprint of temporal-context drift — are reproduced by at least three different computations, and only representational decoding separates them. The paper demonstrates this for one task. The natural extension is to make it a general identifiability protocol: for a given behavioural summary statistic, train a large population of task-optimized models, cluster them by internal representation rather than by fit, and report the size of the mechanism equivalence class that the statistic admits. That turns "my model fits the curve" into a quantified claim about how much the curve could possibly constrain.

Added value to my researchThis is a direct indictment of a habit in my own field. In 2SFCA/R2SFCA work, a fitted distance-decay curve is routinely read as evidence for a behavioural mechanism (willingness to travel), and in MGWR a bandwidth surface is read as evidence for a scale of process. The paper says: multiple distinct generative processes can produce the same decay curve or the same bandwidth map. Practical import for my pipeline — before publishing a decay parameter as a behavioural finding, run the model-population test: simulate several competing mechanisms (capacity competition, information asymmetry, habitual anchoring) and check whether the fitted curve can distinguish them at all. If not, report the equivalence class honestly rather than the single interpretation.

③ Make the objective function a covariate: strategy as a function of who is recalling and why

Extending this paperThe paper identifies two knobs that select a strategy — the discount factor (recall all vs. the next few) and working-memory flushing (recency availability) — and shows strategy correlates with performance in both models and 186 PEERS participants. But it does not close the loop per individual. The strong extension: fit each human participant's own (γ, WM-flush) pair by finding the trained model whose behavioural fingerprint best matches theirs, then ask whether the recovered γ predicts independent traits — the corpus's own references link temporal discounting to executive function and exploration. That would convert "individual differences in memory" into an estimated objective-function parameter with external validity, and give a principled target for mnemonic training (train people into the high-γ, low-recency regime).

Added value to my researchThis is a template I can lift wholesale for health-service-seeking behaviour. In telehealth and primary-care access work I treat heterogeneity as a nuisance to be absorbed by fixed effects or by MGWR's varying coefficients. Instead: build a small population of task-optimized agents choosing among care options under different objectives (short-horizon urgency vs. long-horizon continuity of care, with/without local memory of past providers), fit an objective parameter per neighbourhood or per subgroup, and map that parameter. A "discount factor map" of care-seeking would be a far more actionable policy object than a residual map — it says why a district under-uses preventive care, not just that it does.

④ Index vs. identity as a general disentanglement axis — and a decoding protocol for spatial models

Extending this paperThe key–value ablation (Extended Data Fig. 1) delivers a crisp dissociation: keys carry index, values carry identity. This is an unusually clean case of a network spontaneously factorizing "where in the sequence" from "what". The paper reports it as a side observation; it deserves to be the centrepiece. Extension: measure the factorization with an explicit disentanglement objective — sparsity/superposition analysis of the hidden state — and test whether enforcing the index/identity split (e.g. an orthogonality or sparsity penalty) makes the memory-palace strategy emerge more reliably, faster, and at longer list lengths. That would move the paper from "the good strategy sometimes appears" to "here is how to induce it", which matters for anyone building episodic memory into an agent.

Added value to my researchThe where/what factorization is the central unsolved problem in my geospatial foundation-model fine-tuning. When I adapt a pretrained remote-sensing or mobility encoder, the embedding entangles location identity (this is Wuhan) with spatial-structural role (this is a dense mixed-use core), which is precisely why models transfer badly across cities. The paper's protocol gives me a concrete diagnostic — train separate linear decoders for place-identity and for structural-role, then run cross-decoding across cities; a truly transferable geospatial representation should show high cross-city role decoding and low identity leakage. That is a measurable transferability metric, not a vibe, and it plugs straight into my explainable-ML agenda.

⑤ Put the scaffold back in space: route-based recall as a model of activity-space memory

Extending this paperThe paper reaches for a spatial metaphor (memory palace) while its task is entirely non-spatial — items arrive in a list, and the environment supplies no structure to hang memories on. The most creative extension is to give the agent a real environment: let items be encountered while traversing a graph or a 2-D layout, so that a genuine external scaffold is available for free. Then ask the paper's own question — does the network still invent an internal index, or does it offload the scaffold to the world? Fig. 5 already shows that supplying external temporal context pulls models toward TCM; supplying external spatial context is the untested and more interesting case, and it would tell us when cognitive offloading beats internal indexing. Testing capacity limits (how long a list a scaffold supports) and interference across repeated environments would round it out.

Added value to my researchThis is the bridge to my activity-space and accessibility work. If human recall of visited places is scaffolded by route order rather than by Euclidean or network distance, then perceived accessibility is a function of position in a habitual sequence, not just travel time — a facility on the daily commute chain is cognitively "closer" than an equidistant facility off-chain. That is a testable amendment to my 2SFCA family: add a sequence-position term to the impedance function, estimated from mobile-phone or GPS trajectory chains, and check whether it improves prediction of realized primary-care and mental-health utilization over pure travel-time decay. It also reframes 15-minute-neighbourhood evaluation: proximity that is off the habitual route may deliver far less real access than the map suggests.
