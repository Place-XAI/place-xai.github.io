Algorithm–hardware co-design of neuromorphic networks with dual memory pathways

Pengfei Sun · Zhe Su · Jascha Achterberg · Giacomo Indiveri · Dan F. M. Goodman · Danyal Akarca Published 2026-06-16 DOI 10.1038/s42256-026-01255-3 Source nature.com ↗
Core Conclusion

Long-range temporal memory in spiking networks does not have to be bought with dense recurrence or deep delay buffers. Borrowing the cortical fast–slow motif, each layer is given one compact, layer-shared slow state (a Legendre/state-space memory of dimension d ≈ 5–10% of the hidden width) that summarizes recent activity and modulates fast spiking. This dual memory pathway (DMP-SNN) matches or beats state-of-the-art SNNs on long-sequence benchmarks (99.3% S-MNIST, 97.3% PS-MNIST) with 40–60% fewer parameters, while a co-designed 22FDX near-memory-compute accelerator turns the same structural choice into silicon gains: >4× throughput and >5× energy efficiency over state-of-the-art delay-based implementations. The message is a design principle: make the slow state explicit, shared and low-rank; keep the fast path spike-driven; run the two in parallel.

★

Why It Matters

  • Dissolves a standing trade-off in neuromorphic computing. Temporal competence (recurrence, learnable axonal delays) has historically cost exactly what neuromorphic hardware is meant to save — area, memory traffic, energy. The paper shows the tension is an artifact of where memory is placed, not a law: one shared low-rank state per layer scales as 𝒪(d) instead of 𝒪(N²).
  • Co-design is carried all the way to post-layout silicon. Results are not simulator throughput claims: post-layout simulation in a 22FDX node, benchmarked against Loihi 2, DenRAM, ReckOn and ElfCore, with area and energy per time step reported — over 1.9× throughput vs recurrent hardware and >2× area efficiency vs ReckOn.
  • Long delays become optional rather than structural. With a slow state present, learned axonal delays shift towards shorter horizons and the long-delay tail contracts — removing the deep programmable buffers (or analogue capacitor arrays) that dominate delay-based designs' cost.
  • It repairs long-range credit assignment. Under last-time-step supervision, gradients survive the full 784 steps of S-MNIST because the memory block's spectral radius sits near one, whereas a purely feedforward SNN's gradients vanish at rate βT−k. The slow state is a training device, not just an inference buffer.
  • Fully open. Algorithm and hardware source are released (GitHub, Zenodo), which is rare for accelerator work and makes the co-design reproducible.

Core Methods

  • Fast pathway — LIF spiking: membrane ul[k] = β ul[k−1] + Il[k] with feedforward current Wf sl−1[k] and Heaviside spiking at threshold; variants add axonal delays or intra-layer recurrence as comparison baselines.
  • Slow pathway — compact state-space memory: a Legendre-memory-unit-style linear system ml[k] = Ā ml[k−1] + B̄ xl[k], with A, B from the Padé/Legendre construction and zero-order-hold discretization; Ā, B̄ are frozen during training. Presynaptic spikes are compressed to a scalar drive xl[k] = f(Wx sl−1[k] + b), so the state is layer-shared rather than per-synapse.
  • Coupling: the memory re-enters the membrane as an extra current Im = Wm ml[k] — modulation, not replacement: deleting the fast feedforward drive collapses accuracy to chance at any memory size.
  • Gradient/spectral analysis: stacking (u, m) gives a block-upper-triangular transition F whose spectrum is {β} ∪ spec(Ā); since ρ(Ā) ≈ 1, memory-aligned modes carry gradients far beyond the membrane's βT−k decay — a two-timescale credit-assignment argument.
  • Design-space probes: dilated slow memory (update every ds steps) to test how often context must refresh; iso-accuracy contours over (memory dimension, state-buffer length θ); hybrid with heterogeneous axonal delays showing delay mass shifting to shorter horizons as θ grows.
  • Hardware — dependency breaking: four parallel data paths (spike integration, two memory-integration paths, memory update); because the slow update is linear, P m[k−1] is computed in parallel with forming v x[k], balancing critical paths.
  • Hardware — operator fusion: leaky update, spike integration and memory integration fused into a single pass with register-slot accumulation → one SRAM access per neuron, pushing the design into the compute-bound region of the roofline.
  • Hardware — heterogeneous operand stationarity: input-stationary (column-stationary) access for sparse spike integration, output-stationary (row-stationary) for the dense memory vector-matrix product; the compact state stays on-chip, eliminating off-chip traffic.
  • Evaluation protocol: networks trained offline; reported accuracies are hardware-inference measurements; ablation against an ElfCore-style implementation without fusion/stationarity isolates the architectural contribution.

① Take the dual pathway off the benchmark bench and onto continuous real-world event streams

Extending this paperEvery claim rests on curated, episodic benchmarks — SHD/SSC utterances, 784-step MNIST streams, DVS gestures — where sequences are short, segmented and stationary. Real event streams (urban acoustic/seismic sensing, traffic detectors, ambient health monitors) are unsegmented, non-stationary and run for hours, exactly the regime where a fixed Legendre window θ and a frozen Ā are most likely to break. The direct extension: build a continuous-stream evaluation with drift and silence, and let each layer learn or adapt θ online (or maintain a small bank of θ-scales), testing whether the paper's "short buffers suffice" conclusion survives outside episodic data.

Added value to my researchThis is the missing compute substrate for always-on urban sensing in my work: an event-driven encoder that runs at sensor level and only emits summaries, so a city-scale spatiotemporal KDE or exposure model is fed by pre-compressed streams instead of raw telemetry — decisive when the sensing layer is bandwidth- and power-limited.

② Give the slow state a geography: from layer-shared scalar memory to a graph-structured slow pathway

Extending this paperThe paper's compression is aggressive in a specific way: all presynaptic spikes are squeezed into a scalar drive x[k] before entering the memory, so the slow state carries when but has deliberately discarded where. That is fine for a 700-channel cochleagram and fatal for spatially organized inputs. Extension: replace the scalar drive with a node-indexed drive over a sensor/region graph and couple the per-node states through a graph operator (a spatial Ā), yielding a DMP-GNN whose parameter count stays 𝒪(nodes × d) — then check whether the hardware's dependency-breaking trick still holds when the memory update is no longer a single small matrix-vector product.

Added value to my researchThis lands squarely in my physics-informed graph-learning agenda: each census tract or facility node keeps a low-rank Legendre memory of its own demand/mobility history, with the graph operator enforcing spatial coupling — an interpretable, cheap alternative to stacking spatiotemporal transformers for accessibility and service-demand forecasting.

Cross-ref (corpus): Transferable human mobility network reconstruction with neuroGravity — 10.1038/s43588-026-01003-y

③ Read the memory: turn the Legendre coefficients into a timescale-attribution instrument

Extending this paperThe paper treats m purely as machinery, yet it is an orthogonal polynomial basis over a sliding window — each coordinate has an unambiguous temporal meaning. That makes the model unusually interpretable and the paper never cashes it in. Extension: run per-coefficient ablation and gradient attribution to measure which temporal horizon actually drives each decision, and use it to explain the paper's own puzzle (why auditory tasks collapse under dilation while permuted vision does not). Benchmarking this against fixed random reservoirs would also test whether structured, readable memory beats unstructured transients at equal cost.

Added value to my researchA clean temporal analogue of what MGWR bandwidths give me spatially: instead of "the model attends to the past", I get a calibrated scale decomposition — how much of a mental-health-service demand or mobility prediction comes from hours vs weeks — which is exactly the currency policy audiences accept from explainable spatiotemporal models.

④ Replace hand-tuned (d, θ, dilation, N) with a budget-aware automatic allocator

Extending this paperThe paper's own evidence — accuracy saturates once task timescales are captured, and "capacity should be co-tuned rather than maximized" — indicts its methodology: those four knobs are still swept by hand per dataset (Extended Data Table 4), and the two highlighted operating points are picked off an iso-accuracy contour by eye. Extension: treat d as a compression rank and learn the allocation under an explicit energy/area budget, borrowing sketching and low-rank compression theory to predict the minimal d from the signal's spectrum instead of discovering it by grid search — turning a manual design space into a solvable one.

Added value to my researchThe same budget-first framing applies to my deployable GeoAI models: choose model rank from an energy/latency budget rather than from validation accuracy alone — essential when spatial prediction has to run in low-resource or edge settings, and a concrete step toward reporting energy cost alongside accuracy in reproducible/FAIR model cards.

Cross-ref (corpus): Random sketch learning for deep neural networks in edge computing — 10.1038/s43588-021-00039-6

⑤ Push the co-design to on-body silicon — and make energy an equity argument

Extending this paperThe accelerator is post-layout in a 22FDX node, evaluated on a lab benchmark; the paper explicitly positions DMP-SNN for "extreme edge" sensor-level processing but never demonstrates an end-to-end sensor→inference deployment. Extension: port the architecture onto a flexible or compute-in-memory substrate, drive it with a real always-on physiological/acoustic sensor, and report joules per hour of continuous monitoring plus accuracy drift over days — the metrics that decide whether the >5× efficiency claim matters in the field rather than on a test set.

Added value to my researchThis connects hardware efficiency to my digital-divide and telehealth work: inference that survives on-device removes the dependence on continuous connectivity and cloud cost, which is precisely the constraint that makes remote monitoring inequitable in rural and low-broadband areas — an energy-per-inference argument with a health-geography payoff, and one that keeps sensitive health streams local by construction.
